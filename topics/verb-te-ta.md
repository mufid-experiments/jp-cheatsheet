## The whole thing at a glance

> **1. Find the type** (ru / u / exception) → **2. Find the stem** → **3. Add** て (*and, please, ongoing*) **or** た (*past*).
>
> Ru-verb: drop **る**. U-verb: the last kana changes. Only 3 verbs break the rules: <ruby>行<rt>い</rt></ruby>く・する・<ruby>来<rt>く</rt></ruby>る.
{: .formula}

| Type | Dictionary form | ます-stem | て-form | た-form |
|------|-----------------|-----------|---------|---------|
| **Ru-verb** | <ruby>食<rt>た</rt></ruby>べ**る**<br>*eat* | <ruby>食<rt>た</rt></ruby>べ | <ruby>食<rt>た</rt></ruby>べ**て** | <ruby>食<rt>た</rt></ruby>べ**た** |
| **U-verb** | <ruby>書<rt>か</rt></ruby>**く**<br>*write* | <ruby>書<rt>か</rt></ruby>**き** | <ruby>書<rt>か</rt></ruby>**いて** | <ruby>書<rt>か</rt></ruby>**いた** |
| **Exception** | <ruby>行<rt>い</rt></ruby>**く**<br>*go* | <ruby>行<rt>い</rt></ruby>**き** | <ruby>行<rt>い</rt></ruby>**って** | <ruby>行<rt>い</rt></ruby>**った** |
| **Exception** | する<br>*do* | **し** | **して** | **した** |
| **Exception** | <ruby>来<rt>く</rt></ruby>る<br>*come* | <ruby>来<rt>き</rt></ruby> | <ruby>来<rt>き</rt></ruby>**て** | <ruby>来<rt>き</rt></ruby>**た** |
{: .grid}

## 1. Ru-verb or u-verb?

<div class="cols" markdown="1">
<div markdown="1">

> **Ru-verb** (group 2)
>
> Ends in **いる** or **える**. Only the る is ever dropped; the rest is the **stem** and never changes.

| Verb | Meaning |
|------|---------|
| <ruby>食<rt>た</rt></ruby>べる | *eat* |
| <ruby>見<rt>み</rt></ruby>る | *see, watch* |
| <ruby>起<rt>お</rt></ruby>きる | *wake up* |
| <ruby>寝<rt>ね</rt></ruby>る | *sleep* |
| <ruby>教<rt>おし</rt></ruby>える | *teach* |
| <ruby>着<rt>き</rt></ruby>る | *wear* |
{: .plain .compact}

</div>
<div markdown="1">

> **U-verb** (group 1)
>
> Ends in **う く ぐ す つ ぬ ぶ む**, or in **る** after あ・う・お. The last kana moves along the row (<ruby>書<rt>か</rt></ruby>く → <ruby>書<rt>か</rt></ruby>き・<ruby>書<rt>か</rt></ruby>か・<ruby>書<rt>か</rt></ruby>け ...).

| Verb | Meaning |
|------|---------|
| <ruby>買<rt>か</rt></ruby>う | *buy* |
| <ruby>書<rt>か</rt></ruby>く | *write* |
| <ruby>話<rt>はな</rt></ruby>す | *speak* |
| <ruby>待<rt>ま</rt></ruby>つ | *wait* |
| <ruby>読<rt>よ</rt></ruby>む | *read* |
| <ruby>乗<rt>の</rt></ruby>る | *ride* |
{: .plain .compact}

</div>
</div>

> **Look-alikes: they end in いる・える but are u-verbs.** Learn them as they come:
> <ruby>帰<rt>かえ</rt></ruby>る *return* ・ <ruby>入<rt>はい</rt></ruby>る *enter* ・ <ruby>切<rt>き</rt></ruby>る *cut* ・ <ruby>知<rt>し</rt></ruby>る *know* ・ <ruby>走<rt>はし</rt></ruby>る *run* ・ <ruby>要<rt>い</rt></ruby>る *need* ・ <ruby>減<rt>へ</rt></ruby>る *decrease* ・ <ruby>喋<rt>しゃべ</rt></ruby>る *chat* ・ <ruby>蹴<rt>け</rt></ruby>る *kick*
>
> Same sound, two types: <ruby>着<rt>き</rt></ruby>る *wear* (ru) → <ruby>着<rt>き</rt></ruby>**て**　vs.　<ruby>切<rt>き</rt></ruby>る *cut* (u) → <ruby>切<rt>き</rt></ruby>**って**.
{: .warn}

## 2. Ru-verb: drop る, add て / た
{: .new-page}

> **<ruby>食<rt>た</rt></ruby>べる → <ruby>食<rt>た</rt></ruby>べ + て / た**
>
> No exceptions. The stem is whatever is left after る.
{: .formula}

| Dictionary | Stem | て-form | た-form | |
|------------|------|---------|---------|-|
| <ruby>食<rt>た</rt></ruby>べる | <ruby>食<rt>た</rt></ruby>べ | <ruby>食<rt>た</rt></ruby>べ**て** | <ruby>食<rt>た</rt></ruby>べ**た** | eat |
| <ruby>見<rt>み</rt></ruby>る | <ruby>見<rt>み</rt></ruby> | <ruby>見<rt>み</rt></ruby>**て** | <ruby>見<rt>み</rt></ruby>**た** | see |
| <ruby>起<rt>お</rt></ruby>きる | <ruby>起<rt>お</rt></ruby>き | <ruby>起<rt>お</rt></ruby>き**て** | <ruby>起<rt>お</rt></ruby>き**た** | wake up |
| <ruby>寝<rt>ね</rt></ruby>る | <ruby>寝<rt>ね</rt></ruby> | <ruby>寝<rt>ね</rt></ruby>**て** | <ruby>寝<rt>ね</rt></ruby>**た** | sleep |
| <ruby>教<rt>おし</rt></ruby>える | <ruby>教<rt>おし</rt></ruby>え | <ruby>教<rt>おし</rt></ruby>え**て** | <ruby>教<rt>おし</rt></ruby>え**た** | teach |
| <ruby>出<rt>で</rt></ruby>る | <ruby>出<rt>で</rt></ruby> | <ruby>出<rt>で</rt></ruby>**て** | <ruby>出<rt>で</rt></ruby>**た** | go out |
{: .plain .pair}

## 3. U-verb: look at the last kana

> **The last kana decides.** て-form and た-form change together; only the て / た (or で / だ) at the end differs.
>
> **Shortcut:** make the た-form, then change た → て, だ → で. <ruby>読<rt>よ</rt></ruby>んだ → <ruby>読<rt>よ</rt></ruby>ん**で**.
{: .formula}

| Ends in | ます-stem | て-form | た-form | Example |
|---------|-----------|---------|---------|---------|
| う | い | **って** | **った** | <ruby>買<rt>か</rt></ruby>う → <ruby>買<rt>か</rt></ruby>**って** → <ruby>買<rt>か</rt></ruby>**った** |
| つ | ち | **って** | **った** | <ruby>待<rt>ま</rt></ruby>つ → <ruby>待<rt>ま</rt></ruby>**って** → <ruby>待<rt>ま</rt></ruby>**った** |
| る | り | **って** | **った** | <ruby>乗<rt>の</rt></ruby>る → <ruby>乗<rt>の</rt></ruby>**って** → <ruby>乗<rt>の</rt></ruby>**った** |
| む | み | **んで** | **んだ** | <ruby>読<rt>よ</rt></ruby>む → <ruby>読<rt>よ</rt></ruby>**んで** → <ruby>読<rt>よ</rt></ruby>**んだ** |
| ぶ | び | **んで** | **んだ** | <ruby>遊<rt>あそ</rt></ruby>ぶ → <ruby>遊<rt>あそ</rt></ruby>**んで** → <ruby>遊<rt>あそ</rt></ruby>**んだ** |
| ぬ | に | **んで** | **んだ** | <ruby>死<rt>し</rt></ruby>ぬ → <ruby>死<rt>し</rt></ruby>**んで** → <ruby>死<rt>し</rt></ruby>**んだ** |
| く | き | **いて** | **いた** | <ruby>書<rt>か</rt></ruby>く → <ruby>書<rt>か</rt></ruby>**いて** → <ruby>書<rt>か</rt></ruby>**いた** |
| ぐ | ぎ | **いで** | **いだ** | <ruby>泳<rt>およ</rt></ruby>ぐ → <ruby>泳<rt>およ</rt></ruby>**いで** → <ruby>泳<rt>およ</rt></ruby>**いだ** |
| す | し | **して** | **した** | <ruby>話<rt>はな</rt></ruby>す → <ruby>話<rt>はな</rt></ruby>**して** → <ruby>話<rt>はな</rt></ruby>**した** |
{: .plain .compact}

> **Remember by sound:** う・つ・る → small **っ** (*tsu* stops) ・ む・ぶ・ぬ → **ん** (nasal; て becomes **で**) ・ く・ぐ → **い** (ぐ also voices: **で**) ・ す → **し**.
{: .warn}

## 4. Exceptions
{: .new-page}

<div class="cols" markdown="1">
<div markdown="1">

> **<ruby>行<rt>い</rt></ruby>く breaks the く rule**
>
> <ruby>行<rt>い</rt></ruby>く → <ruby>行<rt>い</rt></ruby>**って** ・ <ruby>行<rt>い</rt></ruby>**った**
>
> <span class="bad"><ruby>行<rt>い</rt></ruby>いて　<ruby>行<rt>い</rt></ruby>いた</span>
{: .warn}

> **する** and **<ruby>来<rt>く</rt></ruby>る** are fully irregular: learn them by heart.
>
> する → し**て**・し**た**　<ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>き</rt></ruby>**て**・<ruby>来<rt>き</rt></ruby>**た**
>
> <ruby>来<rt>く</rt></ruby>る is read **く** in the dictionary form but **き** in て / た. Compounds follow: <ruby>勉強<rt>べんきょう</rt></ruby>する → <ruby>勉強<rt>べんきょう</rt></ruby>**して**, <ruby>持<rt>も</rt></ruby>って<ruby>来<rt>く</rt></ruby>る → <ruby>持<rt>も</rt></ruby>って<ruby>来<rt>き</rt></ruby>**て**.

</div>
<div markdown="1">

| Verb | て-form | た-form |
|------|---------|---------|
| <ruby>行<rt>い</rt></ruby>く *go* | <ruby>行<rt>い</rt></ruby>**って** | <ruby>行<rt>い</rt></ruby>**った** |
| <ruby>帰<rt>かえ</rt></ruby>る *return* | <ruby>帰<rt>かえ</rt></ruby>**って** | <ruby>帰<rt>かえ</rt></ruby>**った** |
| する *do* | **して** | **した** |
| <ruby>勉強<rt>べんきょう</rt></ruby>する *study* | <ruby>勉強<rt>べんきょう</rt></ruby>**して** | <ruby>勉強<rt>べんきょう</rt></ruby>**した** |
| <ruby>来<rt>く</rt></ruby>る *come* | <ruby>来<rt>き</rt></ruby>**て** | <ruby>来<rt>き</rt></ruby>**た** |
{: .plain .compact}

> Look-alike u-verbs (<ruby>帰<rt>かえ</rt></ruby>る・<ruby>入<rt>はい</rt></ruby>る・<ruby>切<rt>き</rt></ruby>る・<ruby>知<rt>し</rt></ruby>る・<ruby>走<rt>はし</rt></ruby>る ...) follow the **る → って** rule, not the ru-verb rule.

</div>
</div>

## 5. Using て and た

| | |
|-|-|
| <ruby>昨日<rt>きのう</rt></ruby>、<ruby>映画<rt>えいが</rt></ruby>を<ruby>見<rt>み</rt></ruby>**た**。 | I watched a movie yesterday. *(past, plain)* |
| <ruby>学校<rt>がっこう</rt></ruby>に<ruby>行<rt>い</rt></ruby>**った**。 | I went to school. |
| <ruby>友達<rt>ともだち</rt></ruby>が<ruby>来<rt>き</rt></ruby>**た**。 | A friend came. |
| <ruby>朝<rt>あさ</rt></ruby>、<ruby>起<rt>お</rt></ruby>き**て**、<ruby>顔<rt>かお</rt></ruby>を<ruby>洗<rt>あら</rt></ruby>**って**、ご<ruby>飯<rt>はん</rt></ruby>を<ruby>食<rt>た</rt></ruby>べた。 | I woke up, washed my face, and ate. *(and then ...)* |
| <ruby>本<rt>ほん</rt></ruby>を<ruby>読<rt>よ</rt></ruby>**んで**ください。 | Please read the book. *(request)* |
| <ruby>友達<rt>ともだち</rt></ruby>を<ruby>待<rt>ま</rt></ruby>**って**いる。 | I'm waiting for a friend. *(ongoing)* |
{: .ex .compact}

> **て = unfinished, た = finished.** The て-form never shows tense by itself: the last verb of the sentence does (<ruby>食<rt>た</rt></ruby>べ**た** = past, <ruby>食<rt>た</rt></ruby>べる = non-past). The た-form ends the sentence.
>
> ます-form is just the **ます-stem + ます**: <ruby>書<rt>か</rt></ruby>き**ます**・<ruby>食<rt>た</rt></ruby>べ**ます**・し**ます**・<ruby>来<rt>き</rt></ruby>**ます**.
{: .formula}
