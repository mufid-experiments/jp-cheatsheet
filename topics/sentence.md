## から at a glance

| Meaning | Pattern | Example | |
|---------|---------|---------|---|
| **because / so** | clause + **から**、… | <ruby>暑<rt>あつ</rt></ruby>い**から**、<ruby>窓<rt>まど</rt></ruby>を<ruby>開<rt>あ</rt></ruby>けます。 | *It's hot, so I open the window.* |
| **from** | noun + **から** | <ruby>九時<rt>くじ</rt></ruby>**から**<ruby>働<rt>はたら</rt></ruby>きます。 | *I work from nine.* |
| **after ~ing** | verb て-form + **から** | <ruby>食<rt>た</rt></ruby>べて**から**、<ruby>行<rt>い</rt></ruby>きます。 | *After eating, I'll go.* |
{: .plain .compact}

## 1. ～から: because / so

> **[Reason] から、[Result]。**
>
> "Because [Reason], [Result]." — から attaches to the **reason**, not the result.
{: .formula}

### What comes before から

| Type | Plain (casual) | Polite |
|------|----------------|--------|
| Verb | <ruby>行<rt>い</rt></ruby>く**から** | <ruby>行<rt>い</rt></ruby>きます**から** |
| Verb, past | <ruby>行<rt>い</rt></ruby>った**から** | <ruby>行<rt>い</rt></ruby>きました**から** |
| Verb, negative | <ruby>行<rt>い</rt></ruby>かない**から** | <ruby>行<rt>い</rt></ruby>きません**から** |
| い-adj | <ruby>高<rt>たか</rt></ruby>い**から** | <ruby>高<rt>たか</rt></ruby>いです**から** |
| い-adj, past | <ruby>高<rt>たか</rt></ruby>かった**から** | <ruby>高<rt>たか</rt></ruby>かったです**から** |
| い-adj, negative | <ruby>高<rt>たか</rt></ruby>くない**から** | <ruby>高<rt>たか</rt></ruby>くないです**から** |
| な-adj / noun | <ruby>静<rt>しず</rt></ruby>か**だから** ・ <ruby>雨<rt>あめ</rt></ruby>**だから** | <ruby>静<rt>しず</rt></ruby>か**ですから** ・ <ruby>雨<rt>あめ</rt></ruby>**ですから** |
| な-adj / noun, past | <ruby>静<rt>しず</rt></ruby>か**だったから** | <ruby>静<rt>しず</rt></ruby>か**でしたから** |
| な-adj / noun, negative | <ruby>静<rt>しず</rt></ruby>か**じゃないから** | <ruby>静<rt>しず</rt></ruby>か**じゃありませんから** |
{: .plain .compact}

### Examples

| | |
|-|-|
| <ruby>明日<rt>あした</rt></ruby>は<ruby>試験<rt>しけん</rt></ruby>ですから、<ruby>今晩<rt>こんばん</rt></ruby><ruby>勉強<rt>べんきょう</rt></ruby>します。 | Tomorrow is an exam, so I'll study tonight. |
| <ruby>頭<rt>あたま</rt></ruby>が<ruby>痛<rt>いた</rt></ruby>かったから、<ruby>会社<rt>かいしゃ</rt></ruby>を<ruby>休<rt>やす</rt></ruby>みました。 | I had a headache, so I took the day off work. |
| <ruby>危<rt>あぶ</rt></ruby>ないですから、さわらないでください。 | It's dangerous, so please don't touch it. |
| <ruby>日曜日<rt>にちようび</rt></ruby>は<ruby>休<rt>やす</rt></ruby>みだから、<ruby>家<rt>いえ</rt></ruby>にいます。 | Sunday is a day off, so I'll stay home. |
{: .ex .compact}

> **Answering "Why?"** どうして／なぜ ～ですか。 → ～**から**です。
>
> 「どうして<ruby>遅<rt>おく</rt></ruby>れましたか。」「<ruby>電車<rt>でんしゃ</rt></ruby>が<ruby>止<rt>と</rt></ruby>まった**から**です。」 *"Why were you late?" "Because the train stopped."*

<div class="cols" markdown="1">
<div markdown="1">

> **から vs ので**
>
> Both mean "because". **ので** sounds softer and more polite (good for explaining or excusing). **から** is more direct and personal, and can be followed by requests, commands or invitations.

</div>
<div markdown="1">

> **Polite vs casual**
>
> Match the level of the whole sentence: polite ～ですから、～ます / casual ～だから、～る. Don't mix the two in one sentence.

</div>
</div>

## 2. それから: and then / after that
{: .new-page}

> **[Event 1]。それから、[Event 2]。**
>
> "[Event 1]. And then, [Event 2]." — time order, or the next item in a list.
{: .formula}

| | |
|-|-|
| <ruby>朝<rt>あさ</rt></ruby>、シャワーを<ruby>浴<rt>あ</rt></ruby>びます。**それから**、<ruby>朝<rt>あさ</rt></ruby>ごはんを<ruby>食<rt>た</rt></ruby>べます。 | I take a shower in the morning. Then I eat breakfast. |
| まっすぐ<ruby>行<rt>い</rt></ruby>って、**それから**、<ruby>右<rt>みぎ</rt></ruby>に<ruby>曲<rt>ま</rt></ruby>がってください。 | Go straight, and then turn right. |
| ラーメンと、ギョーザと、**それから**、ビールをください。 | Ramen, gyoza, and also a beer, please. |
{: .ex}

### ～てから: after doing ~ (inside one sentence)

> **[Verb て-form] から、[Action 2]。**
>
> Action 1 happens first, then Action 2. The verb before から is **always て-form**, even in a past sentence.
{: .formula}

| | |
|-|-|
| <ruby>手<rt>て</rt></ruby>を<ruby>洗<rt>あら</rt></ruby>って**から**、<ruby>食<rt>た</rt></ruby>べます。 | I wash my hands, then eat. |
| <ruby>仕事<rt>しごと</rt></ruby>が<ruby>終<rt>お</rt></ruby>わって**から**、<ruby>飲<rt>の</rt></ruby>みに<ruby>行<rt>い</rt></ruby>きます。 | After work ends, I go for a drink. |
| <ruby>宿題<rt>しゅくだい</rt></ruby>をして**から**、テレビを<ruby>見<rt>み</rt></ruby>ました。 | After doing my homework, I watched TV. |
| <ruby>日本<rt>にほん</rt></ruby>に<ruby>来<rt>き</rt></ruby>て**から**、<ruby>三年<rt>さんねん</rt></ruby>になります。 | It has been three years since I came to Japan. |
{: .ex}

<div class="cols" markdown="1">
<div markdown="1">

### て-form quick reference

| Verb type | Ending → て-form | Example |
|-----------|------------------|---------|
| Group 1 | う・つ・る → **って** | <ruby>買<rt>か</rt></ruby>う → <ruby>買<rt>か</rt></ruby>**って** |
| | む・ぶ・ぬ → **んで** | <ruby>飲<rt>の</rt></ruby>む → <ruby>飲<rt>の</rt></ruby>**んで** |
| | く → **いて** | <ruby>書<rt>か</rt></ruby>く → <ruby>書<rt>か</rt></ruby>**いて** |
| | ぐ → **いで** | <ruby>泳<rt>およ</rt></ruby>ぐ → <ruby>泳<rt>およ</rt></ruby>**いで** |
| | す → **して** | <ruby>話<rt>はな</rt></ruby>す → <ruby>話<rt>はな</rt></ruby>**して** |
| Group 2 | る → **て** | <ruby>食<rt>た</rt></ruby>べる → <ruby>食<rt>た</rt></ruby>**べて** |
| Group 3 | irregular | する → **して**<br><ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>き</rt></ruby>**て** |
{: .plain .compact}

> **Exception:** <ruby>行<rt>い</rt></ruby>く → <ruby>行<rt>い</rt></ruby>**って** (not 行いて).

</div>
<div markdown="1">

### Which "after"?

| Pattern | Use |
|---------|-----|
| ～**てから** | A first, then B. A is a clear first step. |
| ～**たあとで** | After A (た-form + あとで). Looser. |
| ～**まえに** | Before A (dictionary form + まえに). |
| **それから** | A separate sentence: "And then…" |
{: .plain .compact}

| Example |
|---------|
| <ruby>食<rt>た</rt></ruby>べた**あとで**、<ruby>歯<rt>は</rt></ruby>をみがきます。<br>*After eating, I brush my teeth.* |
| <ruby>寝<rt>ね</rt></ruby>る**まえに**、<ruby>本<rt>ほん</rt></ruby>を<ruby>読<rt>よ</rt></ruby>みます。<br>*Before sleeping, I read a book.* |
{: .plain .compact}

</div>
</div>

## 3. つまり: in other words / in short
{: .new-page}

> **[A]。つまり、[B]。**
>
> "[A]. In other words, [B]." — B says A again: in simpler words, or boiled down to the point.
{: .formula}

| | |
|-|-|
| この<ruby>人<rt>ひと</rt></ruby>は<ruby>母<rt>はは</rt></ruby>の<ruby>妹<rt>いもうと</rt></ruby>、**つまり**<ruby>私<rt>わたし</rt></ruby>のおばです。 | This is my mother's younger sister — in other words, my aunt. |
| この<ruby>部屋<rt>へや</rt></ruby>は<ruby>広<rt>ひろ</rt></ruby>くて、<ruby>明<rt>あか</rt></ruby>るくて、<ruby>駅<rt>えき</rt></ruby>から<ruby>近<rt>ちか</rt></ruby>いです。**つまり**、<ruby>最高<rt>さいこう</rt></ruby>です。 | This room is big, bright and near the station. In short, it's perfect. *(sum up)* |
| <ruby>部長<rt>ぶちょう</rt></ruby>は「<ruby>考<rt>かんが</rt></ruby>えておきます」と<ruby>言<rt>い</rt></ruby>いました。**つまり**、だめ**ということです**。 | The boss said, "I'll think about it." In other words, it's a no. *(what it really means)* |
| 「<ruby>今<rt>いま</rt></ruby>、お<ruby>金<rt>かね</rt></ruby>がなくて…」「**つまり**、<ruby>貸<rt>か</rt></ruby>して**ってこと**？」 | "I'm out of money right now…" "So you want me to lend you some?" *(casual check)* |
{: .ex}

<div class="cols" markdown="1">
<div markdown="1">

> **つまり … ということです**
>
> The restated part often ends in **～ということです** "it means ~" (casual: **～ってこと**).
>
> 「**つまり**、<ruby>何<rt>なに</rt></ruby>が<ruby>言<rt>い</rt></ruby>いたいの？」 *So what are you trying to say?*

> **Say it:** *tsu-ma-ri*. The つ is the *ts* in "cats", not *su*mari.

</div>
<div markdown="1">

> **だから vs つまり**
>
> Both can be "so" in English.
>
> **だから** = cause → result<br><ruby>雨<rt>あめ</rt></ruby>**だから**、<ruby>行<rt>い</rt></ruby>かない。 *It's raining, so I'm not going.*
>
> **つまり** = the same thing, in other words<br><ruby>母<rt>はは</rt></ruby>の<ruby>妹<rt>いもうと</rt></ruby>、**つまり**おばです。 *My mom's sister, so (= that is) my aunt.*

</div>
</div>

### Similar words

| Word | Meaning | Use |
|------|---------|-----|
| **つまり** | in other words; in short | everyday, in speech and writing |
| **<ruby>要<rt>よう</rt></ruby>するに** | in short; the point is | sums up a long talk; can sound blunt |
| **すなわち** | namely; that is | formal, mostly writing |
| **ということは** | that means… | a conclusion from what someone just said |
{: .plain .compact}

## 4. Other connectors ～
{: .new-page}

| Role | Connector | Meaning | Example |
|------|-----------|---------|---------|
| **Reason → result** | だから / ですから | so, that's why (ですから is polite) | <ruby>雨<rt>あめ</rt></ruby>です。**ですから**、<ruby>行<rt>い</rt></ruby>きません。<br>*It's raining. So I won't go.* |
| | それで | and so (a natural result; no requests or commands after it) | <ruby>電車<rt>でんしゃ</rt></ruby>が<ruby>遅<rt>おく</rt></ruby>れました。**それで**、<ruby>遅刻<rt>ちこく</rt></ruby>しました。<br>*The train was late, so I was late.* |
| **Add / sequence** | そして | and (neutral; joins sentences or events) | <ruby>春<rt>はる</rt></ruby>です。**そして**、<ruby>桜<rt>さくら</rt></ruby>が<ruby>咲<rt>さ</rt></ruby>きます。<br>*It's spring, and the cherry blossoms bloom.* |
| | それから | and then; and also (next in order or list) | <ruby>銀行<rt>ぎんこう</rt></ruby>へ<ruby>行<rt>い</rt></ruby>きます。**それから**、<ruby>買<rt>か</rt></ruby>い<ruby>物<rt>もの</rt></ruby>をします。<br>*I go to the bank. Then I go shopping.* |
| | それに | besides, moreover (another point in the same direction) | この<ruby>部屋<rt>へや</rt></ruby>は<ruby>広<rt>ひろ</rt></ruby>いです。**それに**、<ruby>明<rt>あか</rt></ruby>るいです。<br>*This room is big. Besides, it's bright.* |
| **Contrast** | でも | but, however (casual, starts a sentence) | <ruby>高<rt>たか</rt></ruby>いです。**でも**、<ruby>買<rt>か</rt></ruby>います。<br>*It's expensive. But I'll buy it.* |
| | しかし | however (formal, mostly writing) | <ruby>難<rt>むずか</rt></ruby>しいです。**しかし**、おもしろいです。<br>*It's hard. However, it's interesting.* |
| | が / けど | but (inside a sentence; が is polite, けど is casual) | <ruby>高<rt>たか</rt></ruby>いです**が**、おいしいです。<br>*It's expensive, but delicious.* |
| **Rephrase / sum up** | つまり | in other words, in short (the same thing, said again) | <ruby>来週<rt>らいしゅう</rt></ruby>の<ruby>金曜日<rt>きんようび</rt></ruby>、**つまり**<ruby>十日<rt>とおか</rt></ruby>です。<br>*Next Friday, that is, the 10th.* |
| **Topic / choice** | ところで | by the way | **ところで**、<ruby>明日<rt>あした</rt></ruby>は<ruby>暇<rt>ひま</rt></ruby>ですか。<br>*By the way, are you free tomorrow?* |
| | じゃあ / では | well then, in that case | **じゃあ**、<ruby>始<rt>はじ</rt></ruby>めましょう。<br>*Well then, let's begin.* |
| | たとえば | for example | **たとえば**、りんごやバナナです。<br>*For example, apples and bananas.* |
| | それとも | or (in a question) | コーヒーですか、**それとも**<ruby>紅茶<rt>こうちゃ</rt></ruby>ですか。<br>*Coffee, or tea?* |
{: .connectors}

## Common mistakes

<div class="cols" markdown="1">
<div markdown="1">

> **だ + です**
>
> <span class="bad"><ruby>雨<rt>あめ</rt></ruby>だですから</span>
>
> <span class="good"><ruby>雨<rt>あめ</rt></ruby>ですから</span> or <span class="good"><ruby>雨<rt>あめ</rt></ruby>だから</span>

> **だから vs それから**
>
> **だから** = therefore (cause → result)
>
> **それから** = and then (time order)

</div>
<div markdown="1">

> **て-form vs た-form before から**
>
> <span class="good"><ruby>食<rt>た</rt></ruby>べて**から**、<ruby>寝<rt>ね</rt></ruby>ます。</span> *After eating, I sleep.*
>
> <span class="bad"><ruby>食<rt>た</rt></ruby>べた**から**、<ruby>寝<rt>ね</rt></ruby>ます。</span> *Not "after" at all: "Because I ate, I sleep."*

> **それに vs そして**
>
> **それに** adds a *further* reason or point ("besides").
>
> **そして** just joins ("and").

</div>
</div>
