## The eight endings at a glance

> **When?** non-past / past　**To whom?** informal / formal　**What?** state-of-being / ongoing
>
> Three choices, 2 × 2 × 2 = 8 endings, and only the **last word** changes: だ・です for a state-of-being, いる・います for something ongoing.
{: .formula}

| | | Non-past | Past |
|-|-|----------|------|
| **Informal**<br>*plain* | Only state-of-being | <ruby>学生<rt>がくせい</rt></ruby>**だ**<br>*am a student* | <ruby>学生<rt>がくせい</rt></ruby>**だった**<br>*was a student* |
| | Ongoing | <ruby>勉強<rt>べんきょう</rt></ruby>して**いる**<br>*am studying* | <ruby>勉強<rt>べんきょう</rt></ruby>して**いた**<br>*was studying* |
| **Formal**<br>*polite* | Only state-of-being | <ruby>学生<rt>がくせい</rt></ruby>**です**<br>*am a student* | <ruby>学生<rt>がくせい</rt></ruby>**でした**<br>*was a student* |
| | Ongoing | <ruby>勉強<rt>べんきょう</rt></ruby>して**います**<br>*am studying* | <ruby>勉強<rt>べんきょう</rt></ruby>して**いました**<br>*was studying* |
{: .grid}

## 1. Past or non-past? <small>When?</small>

> **To make the past, change only the last word:**<br>だ → **だった** ・ いる → **いた** ・ です → **でした** ・ います → **いました**
{: .formula}

<div class="cols" markdown="1">
<div markdown="1">

> **Non-past** = now, habits, *and* the future. Japanese has no future tense: a time word or the context tells you when.
>
> **Past** = finished, or how things were.

</div>
<div markdown="1">

| Non-past | Past |
|----------|------|
| <ruby>今<rt>いま</rt></ruby> now | <ruby>昨日<rt>きのう</rt></ruby> yesterday |
| <ruby>毎日<rt>まいにち</rt></ruby> every day | さっき a moment ago |
| <ruby>明日<rt>あした</rt></ruby> tomorrow | <ruby>先週<rt>せんしゅう</rt></ruby> last week |
| <ruby>来週<rt>らいしゅう</rt></ruby> next week | <ruby>去年<rt>きょねん</rt></ruby> last year |
{: .plain .compact}

</div>
</div>

| | |
|-|-|
| <ruby>今日<rt>きょう</rt></ruby>は<ruby>休<rt>やす</rt></ruby>みです。 | Today is a day off. |
| <ruby>明日<rt>あした</rt></ruby>も<ruby>休<rt>やす</rt></ruby>みです。 | Tomorrow is a day off, too. *(future: same form)* |
| <ruby>昨日<rt>きのう</rt></ruby>は<ruby>休<rt>やす</rt></ruby>みでした。 | Yesterday was a day off. |
| <ruby>今<rt>いま</rt></ruby>、<ruby>雨<rt>あめ</rt></ruby>が<ruby>降<rt>ふ</rt></ruby>っています。 | It's raining now. |
| <ruby>明日<rt>あした</rt></ruby>の<ruby>今<rt>いま</rt></ruby>ごろは、<ruby>飛行機<rt>ひこうき</rt></ruby>に<ruby>乗<rt>の</rt></ruby>っています。 | This time tomorrow, I'll be on the plane. *(future: same form)* |
| <ruby>昨日<rt>きのう</rt></ruby>の<ruby>夜<rt>よる</rt></ruby>は<ruby>雨<rt>あめ</rt></ruby>が<ruby>降<rt>ふ</rt></ruby>っていました。 | It was raining last night. |
{: .ex .compact}

## 2. Formal or informal? <small>To whom?</small>
{: .new-page}

> **To make it formal, change only the last word:**<br>だ → **です** ・ だった → **でした** ・ いる → **います** ・ いた → **いました**
{: .formula}

<div class="cols" markdown="1">
<div markdown="1">

> **Informal** <small>(plain: だ・いる)</small>
>
> Friends, family, children; diaries and notes. Also *inside* a sentence, even a formal one (see below).

</div>
<div markdown="1">

> **Formal** <small>(polite: です・ます)</small>
>
> People you don't know well, and people above you: teachers, bosses, customers. The safe default at work and in class.

</div>
</div>

| Informal, to a friend | Formal, to a teacher | |
|-----------------------|----------------------|-|
| <ruby>今日<rt>きょう</rt></ruby>は<ruby>休<rt>やす</rt></ruby>みだ。 | <ruby>今日<rt>きょう</rt></ruby>は<ruby>休<rt>やす</rt></ruby>みです。 | Today is a day off. |
| <ruby>田中<rt>たなか</rt></ruby>さんは<ruby>先生<rt>せんせい</rt></ruby>だった。 | <ruby>田中<rt>たなか</rt></ruby>さんは<ruby>先生<rt>せんせい</rt></ruby>でした。 | Tanaka-san was a teacher. |
| <ruby>今<rt>いま</rt></ruby>、<ruby>料理<rt>りょうり</rt></ruby>をしている。 | <ruby>今<rt>いま</rt></ruby>、<ruby>料理<rt>りょうり</rt></ruby>をしています。 | I'm cooking now. |
| <ruby>何<rt>なに</rt></ruby>をしていた？ | <ruby>何<rt>なに</rt></ruby>をしていましたか。 | What were you doing? |
{: .plain .pair}

<div class="cols" markdown="1">
<div markdown="1">

> **だ is not casual です**
>
> <span class="bad"><ruby>学生<rt>がくせい</rt></ruby>だです</span>　<span class="bad"><ruby>学生<rt>がくせい</rt></ruby>だか？</span>
>
> Formal: <span class="good"><ruby>学生<rt>がくせい</rt></ruby>です</span>　<span class="good"><ruby>学生<rt>がくせい</rt></ruby>ですか。</span>
>
> Informal: <span class="good"><ruby>学生<rt>がくせい</rt></ruby>だ</span>　<span class="good"><ruby>学生<rt>がくせい</rt></ruby>？↗</span>　<span class="good"><ruby>学生<rt>がくせい</rt></ruby>なの？</span>
>
> A casual question drops both だ and か: just let your voice rise.
{: .warn}

> **Casual speech shortcuts**
>
> だ alone sounds firm, so it is often dropped or softened: <ruby>休<rt>やす</rt></ruby>み。・ <ruby>休<rt>やす</rt></ruby>みだよ。
>
> ている loses its い: <ruby>勉強<rt>べんきょう</rt></ruby>し**てる** ・ <ruby>勉強<rt>べんきょう</rt></ruby>し**てた**. Learn the full form first.

</div>
<div markdown="1">

> **Plain form inside a sentence**
>
> Before a noun, use the informal form, even in a formal sentence: <ruby>勉強<rt>べんきょう</rt></ruby>している<ruby>人<rt>ひと</rt></ruby>は<ruby>田中<rt>たなか</rt></ruby>さんです。 *The person studying is Tanaka-san.*

> **"Polite" in Tae Kim**
>
> Tae Kim calls です・ます **polite** (<ruby>丁寧語<rt>ていねいご</rt></ruby>). His **formal** (6.1) is the である style of reports and speeches: <ruby>学生<rt>がくせい</rt></ruby>である・<ruby>学生<rt>がくせい</rt></ruby>であった.

</div>
</div>

## 3. Ongoing or only state-of-being? <small>What?</small>
{: .new-page}

<div class="cols" markdown="1">
<div markdown="1">

### Only state-of-being: *is*

> **[Noun / な-adj] + だ・です**
>
> Says what something *is*. Nothing happens.
{: .formula}

| | Non-past<br>informal / formal | Past<br>informal / formal |
|-|-------------------------------|---------------------------|
| Noun | <ruby>雨<rt>あめ</rt></ruby>**だ**<br><ruby>雨<rt>あめ</rt></ruby>**です** | <ruby>雨<rt>あめ</rt></ruby>**だった**<br><ruby>雨<rt>あめ</rt></ruby>**でした** |
| な-adj | <ruby>静<rt>しず</rt></ruby>か**だ**<br><ruby>静<rt>しず</rt></ruby>か**です** | <ruby>静<rt>しず</rt></ruby>か**だった**<br><ruby>静<rt>しず</rt></ruby>か**でした** |
| い-adj | <ruby>高<rt>たか</rt></ruby>い<br><ruby>高<rt>たか</rt></ruby>い**です** | <ruby>高<rt>たか</rt></ruby>**かった**<br><ruby>高<rt>たか</rt></ruby>**かったです** |

> **い-adjectives take no だ:** <span class="bad"><ruby>高<rt>たか</rt></ruby>いだ</span>　<span class="bad"><ruby>高<rt>たか</rt></ruby>いでした</span>. The adjective carries its own past (<ruby>高<rt>たか</rt></ruby>**かった**); です only makes it polite.
{: .warn}

| | |
|-|-|
| <ruby>私<rt>わたし</rt></ruby>は<ruby>学生<rt>がくせい</rt></ruby>です。 | I'm a student. |
| この<ruby>町<rt>まち</rt></ruby>は<ruby>静<rt>しず</rt></ruby>かだ。 | This town is quiet. |
| <ruby>子供<rt>こども</rt></ruby>のとき、<ruby>野球<rt>やきゅう</rt></ruby>が<ruby>好<rt>す</rt></ruby>きだった。 | As a kid, I liked baseball. |
{: .ex .compact}

</div>
<div markdown="1">

### Ongoing: *is doing*

> **[Verb て-form] + いる・います**
>
> いる = *to exist*: in the middle of an action, or in the state it left.
{: .formula}

| | |
|-|-|
| <ruby>今<rt>いま</rt></ruby>、<ruby>勉強<rt>べんきょう</rt></ruby>しています。 | I'm studying now. |
| <ruby>毎朝<rt>まいあさ</rt></ruby><ruby>走<rt>はし</rt></ruby>っています。 | I run every morning. *(habit)* |
| <ruby>東京<rt>とうきょう</rt></ruby>に<ruby>住<rt>す</rt></ruby>んでいます。 | I live in Tokyo. *(state)* |
| <ruby>姉<rt>あね</rt></ruby>は<ruby>結婚<rt>けっこん</rt></ruby>しています。 | My sister is married. *(result)* |
| <ruby>知<rt>し</rt></ruby>っています。 | I know. *(not* <ruby>知<rt>し</rt></ruby>ります*)* |
{: .ex .compact}

> **Motion verbs: "has gone", not "is going".** <ruby>父<rt>ちち</rt></ruby>は<ruby>駅<rt>えき</rt></ruby>に<ruby>行<rt>い</rt></ruby>っています。 *Dad has gone to the station (he's there now).* On the way there: <ruby>駅<rt>えき</rt></ruby>に<ruby>向<rt>む</rt></ruby>かっています。
{: .warn}

</div>
</div>

<div class="cols" markdown="1">
<div markdown="1">

### Making the て-form

| Verb type | Ending → て-form | Example |
|-----------|------------------|---------|
| Group 1 | う・つ・る → **って** | <ruby>買<rt>か</rt></ruby>う → <ruby>買<rt>か</rt></ruby>**って** |
| | む・ぶ・ぬ → **んで** | <ruby>読<rt>よ</rt></ruby>む → <ruby>読<rt>よ</rt></ruby>**んで** |
| | く → **いて** | <ruby>書<rt>か</rt></ruby>く → <ruby>書<rt>か</rt></ruby>**いて** |
| | ぐ → **いで** | <ruby>泳<rt>およ</rt></ruby>ぐ → <ruby>泳<rt>およ</rt></ruby>**いで** |
| | す → **して** | <ruby>話<rt>はな</rt></ruby>す → <ruby>話<rt>はな</rt></ruby>**して** |
| Group 2 | る → **て** | <ruby>食<rt>た</rt></ruby>べる → <ruby>食<rt>た</rt></ruby>べ**て** |
| Group 3 | irregular | する → **して**<br><ruby>来<rt>く</rt></ruby>る → <ruby>来<rt>き</rt></ruby>**て** |
{: .plain .compact}

> **Exception:** <ruby>行<rt>い</rt></ruby>く → <ruby>行<rt>い</rt></ruby>**って**. **Shortcut:** take the た-form and change た → て, だ → で: <ruby>読<rt>よ</rt></ruby>んだ → <ruby>読<rt>よ</rt></ruby>**んで**. Tae Kim calls Group 1 *u-verbs* and Group 2 *ru-verbs*.

</div>
<div markdown="1">

### ている or the plain verb?

| | |
|-|-|
| <ruby>勉強<rt>べんきょう</rt></ruby>**します**。 | I study. / I will study. |
| <ruby>勉強<rt>べんきょう</rt></ruby>して**います**。 | I'm studying (now). |
| <ruby>食<rt>た</rt></ruby>べ**ました**。 | I ate. *(done)* |
| <ruby>食<rt>た</rt></ruby>べて**いました**。 | I was eating. *(in the middle of it)* |
{: .ex .compact}

> いる is a ru-verb, so the ending conjugates like one: いる → いた ・ います → いました.

</div>
</div>
