## Writing cheatsheets

When creating a cheatsheet, always mention both the Japanese-based book style
(e.g. *ichidan*) and the English-based book style (e.g. ichidan is *ru-verb* or
*る-verb*), so a reader can follow it whichever kind of textbook they learned
from.

| Japanese-based | English-based |
|----------------|---------------|
| 五段 *godan* | u-verb / う-verb |
| 一段 *ichidan* (上一段 *kami-ichidan*, 下一段 *shimo-ichidan*) | ru-verb / る-verb |
| カ変 *ka-hen* (来る), サ変 *sa-hen* (する) | irregular verb |
| 形容詞 *keiyōshi* | i-adjective / い-adjective |
| 形容動詞 *keiyōdōshi* | na-adjective / な-adjective |

`topics/verb-te-ta.md` is a good model:
`Ru-verb (<ruby>一段<rt>いちだん</rt></ruby>, *ichidan*)`.
